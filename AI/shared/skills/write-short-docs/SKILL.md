# Write Short Docs

- Viết tiếng Việt có dấu hoặc theo ngôn ngữ hiện tại của repository.
- Ưu tiên path, command, checklist và ví dụ Dart ngắn đã được kiểm tra.
- Dùng đúng tên package, public API, SDK constraint và platform support từ source.
- Không lặp giải thích đã có; liên kết tới tài liệu gốc.
- Docs mới phải được liên kết từ README hoặc index gần nhất.
- Không dùng `latest_version`, placeholder hoặc platform chưa hỗ trợ trong ví dụ phát hành.
