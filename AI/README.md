# AI

Tài liệu giúp AI làm việc nhất quán trong các package và plugin Dart/Flutter của workspace.

- `shared/project-context.md`: cách đọc cấu trúc và loại package hiện tại.
- `shared/flutter-upgrade-order.md`: thứ tự nâng cấp các repository trong workspace.
- `shared/agent-rules.md`: quy tắc chung khi sửa code.
- `shared/code-review-checklist.md`: checklist trước khi bàn giao.
- `shared/docs-style.md`: quy ước tài liệu.
- `shared/skills/flutter-upgrade`: quy trình nâng Flutter/Dart và dependency.
- `shared/skills/platform-channel`: quy trình sửa plugin đa nền tảng.
- `shared/skills/code-health`: kiểm tra phần Dart/Flutter đang thay đổi.
- `shared/skills/write-code-flow`: ghi lại luồng API hoặc platform channel.
- `shared/skills/write-short-docs`: viết tài liệu kỹ thuật ngắn.
- `codex/AGENTS.md`: quy tắc riêng cho Codex.
- `antigravity/AGENTS.md`: quy tắc riêng cho Antigravity.

Mỗi agent phải bắt đầu từ `shared/project-context.md`, sau đó chỉ đọc skill liên quan đến task.
